# 与网页版的参数核对

本页记录 training-1、experiment-2、experiment-4-v2、experiment-5-v3 的声音、可视、空白、消失及反馈规则。核对基于当前网页协议、生成器与运行插件；眼动版直接使用这些生成器导出的参数，没有另设固定的运动总时长。所有时间从运动首帧计算，除非注明为提示或注视阶段。

## 阶段与时长

| 实验 | 运动前 | 完全可视与淡出 | 完全消失到查询边界 | 作答与反馈 |
| --- | --- | --- | --- | --- |
| 训练一 | 注视 1000 ms | 不淡出；运动 4 s 后开放速度色带；作答与反馈期间继续往复运动 | 无空白 | 引导/补练确认后反馈 2000 ms；考核确认后直接结束。保留跳过引导和未达标补练流程。 |
| 实验二 | 注视 1000 ms | 完全可视 1.2T；随后摆动淡出 0.25T，旋转淡出 0.5T | 0.7、1.0 或 1.3 s；不包含淡出时长 | 边界时开放估计。练习显示反馈，300 ms 后显示“按空格继续”并允许继续；正式试次确认后直接结束。 |
| 实验四 v2 | 任务提示 1000 ms，再注视 500 ms | 在 blankStartSec 前 300 ms 开始线性淡出；完全可视时间为 blankStartSec−0.3 s | 700 ms；queryTimeSec=blankStartSec+0.7 | 查询时开放角度或速度估计。角度练习反馈立即显示橙蓝摆杆，可按空格继续。速度练习从 t=0 重播到查询边界：遮挡条透明度 0.42，淡出和空白最多盖 0.45 白幕；蓝色速度标记随瞬时真值移动，到边界后停住并显示橙色选择，此后才接受空格。 |
| 实验五 v3 | 任务提示 1000 ms，再注视 500 ms | 在 blankStartSec 前 300 ms 开始线性淡出 | 按试次计算，非固定 700 ms：最低询问铃铛到达时刻前 200 ms 完全消失，查询边界为同侧最高点 | 运动首帧即允许 F/J；可在消失前或查询边界前作答。练习立即从 t=0 重播到查询边界，停在末帧；空格可随时结束反馈，不要求看完整段。 |

T 是该试次的运动周期。实验二的总模拟时长为 `1.2T + fadeMs/1000 + hide1T`；`hide1T` 是历史字段名，实际单位是秒。实验四与五的淡出已经包含在 queryTimeSec 内，不额外延长总时长。实验五提前作答时不强制播放完可视、淡出或空白阶段。

网页参数依据：[训练协议](../../src/experiments/training-1/protocol.ts)、[实验二协议](../../src/experiments/experiment-2/protocol.ts)、[周期与淡出定义](../../src/experiment/physics/timePhases.ts)、[实验四/五共享协议](../../src/experiments/protocol-2/common.ts)、[实验五时序生成](../../src/experiments/experiment-5-v3/approachPlan.ts)。任务提示与注视是生成器已经插入的两个控制单元，不会重复执行插件字段中的提示时长。

## 消失的范围和运动规则

- 训练一的小球持续可见，确认前后均继续运动。
- 实验二只淡出摆杆和摆球；支点、参考线及原协议要求的速度色条继续保留。进入估计阶段后隐藏动态速度条。
- 实验四与五将完整场景渐隐到背景色，包括支点、参考线、遮挡与铃铛；全空白后保留画布外的任务提示。
- 淡出期间仍按当前时间推进物理状态；透明度不会冻结运动。估计真值取查询边界，而非最后可见帧。
- 共享淡出函数也按网页规则处理 blankStartSec 小于 300 ms 的边界输入：从完全可见线性缩短淡出到该时刻。当前正式生成域不会触发这个短淡出分支。

## 声音

使用与网页相同的 masked-hum WAV，文件 SHA-256 为 `B4CF35635DCA70B6CDD6B0DD1390D026967DF73FE53AEB3A29E9D0B03965414E`。原文件为 44.1 kHz、10 s、单声道、峰值 0.25；循环播放时乘以网页 Web Audio 的增益 1.5，默认峰值为 0.375。该增益在波形样本上应用，避免 PsychoPy 的 Sound.volume 将大于 1 的值截断。

边界提示音为 880 Hz 正弦波，总长 80 ms；幅度从 1 在前 70 ms 指数衰减至 0.0001，最后 10 ms 保持该包络值。原生代码生成 48 kHz 波形，关闭 PsychoPy 附加的 Hamming 窗，避免改变包络。

| 实验 | 遮蔽声开始 | 遮蔽声停止 / 提示音 |
| --- | --- | --- |
| 训练一 | 不播放遮蔽声 | 运动 4 s 开放作答时播放一次提示音 |
| 实验二 | 开始淡出 | 全空白期结束、开放估计时停止遮蔽声并播放一次提示音 |
| 实验四 v2 | 开始淡出 | 查询边界停止遮蔽声并播放一次提示音 |
| 实验五 v3 | 开始淡出，前提是尚未作答 | 查询边界停止遮蔽声并播放一次提示音；若提前作答，立即停止遮蔽声，不补响尚未到达的边界提示音 |

网页依据：[playEstimateCue.ts](../../src/shared/playEstimateCue.ts) 及四个运行插件。默认配置保持上述增益；自行修改 mask_volume、cue_volume 或关闭 audio 会改变声音参数。启用声音时初始化失败会明确报错，不会静默忽略。headless 不打开音频设备，音频事件标记为 hardware_audio=false。

## 作答记录与计分修正（2026-11-21）

- `rt_total_sec` 使用确认时刻减作答开放时刻，排除提示、注视、刺激等待和确认后的反馈。实验五从运动首帧开放作答；其他三个实验从报告界面首帧开始计时。没有确认的试次保留空值，不以整段呈现时长代替。
- 鼠标已经选择但尚未确认时，立即保留最新估计及首次操作反应时；中断记录仍有该选择，而确认时刻、总反应时保持为空。实验五尚未按 F/J 就中断时，判断、正误及反应时均为空，不写成错误答案。
- CSV 列包含网页行为列、全部试次描述列、被试资料及原生计时字段；JSONL 保留完整记录。CSV 遇到未声明的新字段会明确报错，避免静默丢列。记录先写入 JSONL，再写 CSV；JSONL 可用于恢复异常保存时的数据。
- `feedback_shown` 保留网页描述符的协议含义；`feedback_available` 表示该试次安排反馈；`feedback_presented` 表示反馈首帧已实际翻屏。跳过引导的状态不会泄漏到随后考核的 `feedback_phase_skipped`。
- 训练记录保留 `report_available_at_sec` 与 `first_traversal_duration_sec`。前者为固定 4 s；后者是轨道全长除线速度，静止试次为空，二者不可互换。
- 只有完整结束的考核呈现参与达标判定；反馈或呈现中断后的重新呈现不会重复计入。达标条件保持平均绝对误差 ≤0.15，且六次中至少五次误差 ≤0.25。
- 实验二的角度误差在摆动和旋转条件均归一化至 `(-180°, 180°]`，精确半周边界为 +180°。实验四保持直接相减。实验四保存未截断的物理速度真值 `L × |ω|`，只将色带位置限制在 `[0, 1]`，速度误差使用原始物理真值。

## 物理与设计核对

摆动采用与网页相同的椭圆函数解，SciPy 的参数使用 `m=k²`；旋转采用 velocity Verlet，子步长不超过 1/4000 s。训练使用原协议的匀速往复与静止规则，并容忍浮点数在轨道端点附近的微小误差。预取查询真值之后将运动状态回到 t=0，保证正式播放与练习回放从正确初态开始。

核对当前生成会话：实验二查询末态角度/角速度与网页导出真值的最大误差分别为 `7.64e-14 rad` / `9.73e-14 rad/s`；全部 49 个旋转条件按 60 Hz 逐帧推进与直接求末态相比，最大误差为 `3.56e-9 rad` / `2.37e-9 rad/s`，均低于 `1e-7` 测试容差。实验五 40 个描述符的查询位置均为同侧最高点，振幅最大误差 `1.43e-14°`，查询时 `|ω|≤2.81e-15 rad/s`；消失后 200 ms 的位置与 `amplitudeDeg−9°` 的最大误差为 `7.11e-14°`。

| 会话 | 导出试次描述数 | 正式试次数 | 首轮正常运行呈现数 |
| --- | ---: | ---: | ---: |
| training-1 | 44 | 0 | 30（24 引导 + 6 考核） |
| experiment-2 | 159 | 150 | 159 |
| experiment-4-v2 | 108 | 96 | 108 |
| experiment-5-v3 | 40 | 36 | 40 |

训练导出包含备用补练和重考模板，因此描述数与首轮运行数不同。失败后按 8 补练 + 6 重考循环；连续两轮失败、第三轮通过时为 58 次呈现。跳过引导不跳过考核或后续必要补练。

## 最新网页修改与 EyeLink 同步（2026-11-21）

GUI 与命令行 `--experiment` 每次开始均调用当前网页生成器；训练一、实验四 v2、实验五 v3 简化后的指导语会直接进入新会话。导出测试逐字核对当前 welcome 文本及指导语、实验五插件的源码 SHA-256。显式 `--session` 保持归档时的文本与参数，不会随源码更新；`--validate` 不检查源码新鲜度。

实验五练习动态反馈文字已统一为网页版的“正确/错误。这个铃铛可以/不可以到达。下面再看一次遮挡后面的运动。按空格继续。”。回放保持两侧 0.42 透明度遮挡、中间透明狭缝；双方均没有另绘狭缝边界线。

核对安装的 PyLink SDK 后修正录制开始判断：`waitForBlockStart(1000, 1, 1)` 返回 0 表示等待超时，正值表示收到数据块，与 `startRecording()` 的 0 成功返回约定不同。超时现在停止录制、报告错误，并继续关闭/传回主机 EDF 的清理流程；不会继续刺激呈现。`isRecording()` 继续按 SDK 的 `TRIAL_OK=0` 判断，并单独兼容布尔返回。

## 保留的运行差异

眼动版将失焦视为呈现中断，保存中断记录后从提示/注视重新开始当前试次，并分配新的 presentation_id。网页部分插件恢复时扣除暂停时长后继续原试次。因此正常试次的参数与规则对齐，失焦后的恢复策略不同。

实验五练习回放的首个原生反馈帧明确取 t=0，网页首个 requestAnimationFrame 按当时已过去的时间绘制；眼动版在反馈首帧后清理此前的按键缓存。因此反馈切换瞬间存在帧级实现差别，之后均可立即按空格退出，不设看完回放的门槛。

网页采用 requestAnimationFrame 和浏览器音频调度；眼动版采用 PsychoPy 翻屏回调触发声音。时长均受实际刷新率量化，逐帧日志可检查软件侧时序，但参数和自动测试不能证明显示器、声卡或 EyeLink 的物理延迟相同。现场验收见 [README](../README.md#正式采集前的设备验收)。
