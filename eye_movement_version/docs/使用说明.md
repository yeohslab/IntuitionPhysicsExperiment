# 直觉物理眼动实验 · 采集使用说明

这份说明给到现场采集的主试。程序包含四项：训练一（协议 1.0.0）、实验二（协议 2.0.0）、实验四 v2（协议 2.0.0）、实验五 v3（协议 3.0.0）。启动窗口会为每位被试当场生成试次，不需要再打开网页。

请把整个文件夹解压后使用。不要只拷贝其中的 `eye_movement_version`。会话生成需要同级的 `src` 和 `node_modules`。

## 1. 采集电脑

- Windows 64 位。
- 已安装 **Python 3.11 64 位**。安装时勾选 **py launcher**（`py.exe`）。不要用 Microsoft Store 里的 Python，也不要用 3.12 或其他版本。
- 已安装 **Node.js 20 或更高的 64 位版本**（自带 npm）。它只负责生成试次，实验画面本身用 Python。
- 正式采集需要 SR Research EyeLink，主机与这台电脑网线连通。程序默认连接 `100.1.1.1`。
- 建议把本文件夹放在较短的英文路径，例如 `D:\IntuitionEye`。路径太长时，依赖安装可能失败。

Python 可从 [https://www.python.org/downloads/release/python-3119/](https://www.python.org/downloads/release/python-3119/) 下载 Windows installer (64-bit)。Node.js 可安装 20 LTS 或更新的 Current。这两项需要各自的安装包；本压缩包不能代替它们。

## 2. 第一次安装

需要联网，除非压缩包里已经带有 `wheelhouse` 和 `node_modules`（离线安装包）。有这两项目录时，`安装.bat` 不再访问 PyPI 和 npm。

1. 解压整个压缩包。
2. 双击 **`安装.bat`**。
3. 窗口出现「安装完成」后即可关闭。

安装只做一次。它会在 `eye_movement_version\.venv` 里安装 PsychoPy 和 EyeLink 接口，并准备会话生成器。已有 `.venv` 时安装脚本不会覆盖它。若要重装，先确认没有实验窗口还开着，再手动删除 `eye_movement_version\.venv`，然后重新双击 `安装.bat`。

安装结束时的导入检查只说明软件包能加载，不表示已经连上眼动仪。

## 3. 每次采集

1. 打开 EyeLink 主机，确认实验电脑能连上主机。关掉这台电脑的屏保、自动休眠和容易挡住画面的通知。
2. 双击 **`启动实验.bat`**。
3. 在「直觉物理 · 眼动实验」窗口里填写：

| 项目 | 怎么填 |
|---|---|
| 实验 | 训练一、实验二、实验四或实验五 |
| 被试序号 | `1`–`9999` 的整数。同一人做不同实验时用同一个序号。程序会自动加上前缀 |
| 性别 | `0` 男，`1` 女 |
| 年龄 | `1`–`120` 的整数 |
| 眼动仪 | 正式数据选 **`eyelink`**。`dummy` 不连接眼动仪，也不生成 EDF |
| 实验窗口大小 | 默认 **80%**。画面被裁切时再改小，然后重新开始 |

4. 点「开始实验」。程序会生成一套新试次，再打开实验窗口。生成失败时窗口会留下错误文字，已填内容还在，不会写入半份会话。
5. 选择 `eyelink` 后，先完成 EyeLink 校准和漂移检查，再进入指导语。校准是 EyeLink 标准界面：通常按 **C** 开始校准，让被试看依次出现的点；按 **V** 验证；可以接受时按 **回车**。漂移检查时让被试看屏幕中央。界面上的按键提示优先于这段文字。
6. 指导语页面按 **空格** 继续。
7. 做完后实验窗口关闭。把本次运行文件夹拷走（见第 6 节）。

每次点「开始实验」都会生成新的试次顺序，不会从上次中断的地方接着做。中途按 **Esc** 会停止，并保留已经写到硬盘上的数据。这份数据是不完整的：请整段重做，在记录表上注明哪一次作废。不要删除作废文件夹，把它和完整数据一起交回。

实验窗口不要最小化，不要用 Alt+Tab 切走。窗口失焦后，当前试次会整段重做。

## 4. 被试怎么作答

屏幕下方有操作提示，以屏幕文字为准。

- **空格**：翻过指导语；需要时确认回答或继续。
- **Esc**：主试中止实验。已写入的记录保留。
- **实验二、实验四、训练一**：用鼠标在画面上报告角度或速度，再用画面上的确认按钮，或按 **空格 / 回车** 确认。
- **实验五**：可以到达按 **F**，不可以到达按 **J**。运动一开始就可以作答。
- **训练一的引导阶段**：可按屏幕上的跳过，或按 **S**，跳过当前这组带反馈的引导。

练习试次有反馈，正式试次没有。区组之间可以休息，休息页按空格继续。

## 5. 四项实验各有多少试次

| 实验 | 编号 | 内容 |
|---|---|---|
| 训练一 | `T1-0001` 这种形式 | 先做带反馈的速度估计引导，再做测验。未达到掌握标准时会补练并再测，总试次数因人而异 |
| 实验二 | `E2-0001` | 9 个练习 + 150 个正式（3 个区组，每组 50） |
| 实验四 | `E4-0001` | 6 个练习 + 96 个正式（3 个区组，每组 32；角度和速度各一半） |
| 实验五 | `E5-0001` | 4 个练习 + 36 个正式（3 个区组，每组 12） |

同一被试、同一实验可以重复运行。旧记录不会被覆盖。启动页会显示该编号已有多少次运行。

## 6. 数据在哪里，交回什么

每次运行单独占一个文件夹：

```text
eye_movement_version\data\<被试编号>\<实验>\
    <实验>_<被试编号>_<UTC时间>_<随机id>\
```

例如：`eye_movement_version\data\E5-0007\experiment-5-v3\...`

请交回**整个运行文件夹**，不要只拷 `behavior.csv`。文件夹里通常有：

| 文件 | 内容 |
|---|---|
| `status.json` | 是否完成。正式数据应为 `"state": "completed"` |
| `behavior.csv` | 行为记录，可用 Excel 打开 |
| `recording.edf` | 眼动文件。只有 `eyelink` 且成功从主机传回时才有 |
| `session.json` | 本次试次参数和被试编号、性别、年龄 |
| `config.json` | 本次窗口和眼动仪配置 |
| `software.json` | 软件版本 |
| `events.jsonl`、`trials.jsonl`、`frames.jsonl` | 事件、试次和逐帧时间。`frames.jsonl` 可能很大，请一并拷贝 |

另外，`eye_movement_version\sessions\` 里有生成会话的原件。运行文件夹里已经有一份 `session.json`。方便的话把 `sessions` 里对应被试的文件一起交回。

这些文件含有被试编号、性别和年龄。用实验室规定的加密方式传输，不要发到公开网盘，不要提交到 Git。

交回前请打开 `status.json` 看 `state`：

- `completed`：程序正常做完。
- `interrupted`：被 Esc 或类似操作中止，数据不完整。
- `error`：程序出错。请把该文件夹和 `启动实验.bat` 窗口里的文字一起发回。

`eyelink` 运行结束后应有 `recording.edf`，并用 EyeLink Data Viewer 确认能打开。若程序异常退出而文件夹里没有 EDF，请到 EyeLink 主机上查看是否还有未传回的文件（主机上的短文件名以 `E` 开头）。

## 7. 采集前核对

在正式收数据的那台电脑上确认：

- 刺激呈现在被试实际观看的那块屏幕上。默认是第 1 块屏幕（配置里的 `0`）。若应显示在另一块屏幕，见下一节。
- Windows 显示缩放、分辨率和刷新率在整段采集中保持不变。默认按 **60 Hz** 检查丢帧。
- EyeLink 主机坐标与这块屏幕一致，采样率使用实验室既定设置。配置里 `sample_rate` 为 `null` 时，沿用主机当前采样率。
- 校准类型为 **HV13**（13 点），每次正式运行都会做漂移检查。
- 喇叭或耳机有声音。实验会播放掩蔽音和提示音。
- 键盘在英文输入法下，F、J、空格、回车、Esc 都有效。
- 用一位不计入正式样本的试测走通：校准、声音、按键、`recording.edf` 能打开。试测同样会写入 `data`，请在记录表上标明是试测。

`dummy` 只能检查画面和流程，不能代替上述硬件验收。

## 8. 实验室屏幕或眼动仪地址不同时

用记事本打开 `eye_movement_version\config\default.json`，只改需要的项，保存后再双击 `启动实验.bat`。

眼动仪不是 `100.1.1.1` 时，修改：

```json
"tracker": {
  "ip": "100.1.1.1"
}
```

实验窗口应出现在第 2 块屏幕时，把 `window` 里的 `"screen": 0` 改成 `"screen": 1`。屏幕从 0 开始数。

显示器不是 60 Hz 时，把 `timing` 里的 `"expected_refresh_hz": 60` 改成实际刷新率，例如 `120`。请把改过的配置随数据一起交回。

不要改实验试次、按键或时长。那些参数在生成会话时已经定好。

## 9. 常见问题

**双击启动后提示还没有安装。** 先运行 `安装.bat`。

**提示会话生成器不可用，或找不到 Node。** 安装 Node.js 20 或更高版本，再运行一次 `安装.bat`。

**提示找不到 Python 3.11。** 安装 python.org 的 Python 3.11 64 位，并确认能在命令行执行 `py -3.11`。

**点开始后提示无法计算窗口。** 看弹窗里的原文。常见原因是读不到当前屏幕工作区。把窗口大小改成 80% 或更小再试。仍然失败时，把弹窗文字发回。

**连不上眼动仪。** 确认主机已开机、网线接通、IP 与 `config\default.json` 一致。此时不要改选 `dummy` 来充正式数据。

**安装中途失败，再次安装说环境已存在。** 确认没有实验进程后，删除 `eye_movement_version\.venv`，再运行 `安装.bat`。

**杀毒软件拦截。** PsychoPy 或 PyLink 偶发被隔离。把本文件夹加入白名单后，重新运行 `安装.bat`。
