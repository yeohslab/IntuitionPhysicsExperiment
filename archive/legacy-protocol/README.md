# 旧协议数据与分析（归档）

本目录集中存放 **旧版实验协议** 的原始数据、分析输出与分析脚本。与当前 2×3×3、135 正式试次、五位被试编号的线上程序 **分离**。

| 子目录 | 内容 |
|---|---|
| `formal-raw-data/` | 旧协议被试 CSV |
| `analysis-output/` | 旧协议统计结果（表、图、报告） |
| `analysis-pipeline/` | Python 分析脚本（从仓库根 `analysis/` 迁入） |
| `*.md` | 旧协议设计说明、数据字典、审计报告 |

**新实验**：程序结束页将 CSV/JSON **下载到浏览器默认下载目录**（实验室电脑上的「下载」文件夹等）；主试确认保存后，数据在 **仓库外** 做分析，不写入本目录。
