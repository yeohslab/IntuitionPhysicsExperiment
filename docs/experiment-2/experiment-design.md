# 实验二：实验设计

## 研究范式

实验二沿用实验一的单摆观察、淡出、遮挡和终态位置估计任务。差异在于速度辅助信息改为上下两条颜色提示，并由同一被试完成摆动和旋转 Block。

## 被试与结构

- 单组设计；被试编号为 `E2-0001` 至 `E2-9999`。
- 1个混合练习 Block，共9个 Trial，全部提供反馈。
- 20个正式 Block，每个9个 Trial，共180个正式 Trial。
- 20个正式 Block 整体真随机排序；被试编号不作为随机种子。

正式 Block 包含实验一全部15个摆动能量水平，以及旋转最低五个保留能量：`85.75、90.65、95.55、100.45、105.35 J`。每个Block完整覆盖对应运动类型的3×3时序组合：

- 摆动 `show_T = 1.25 / 1.5 / 1.75`；
- 旋转 `show_T = 2.5 / 3.0 / 3.5`；
- 两类均为 `hide_sec = 0.8 / 1.0 / 1.2 s`。

摆动正式 Trial 沿用实验一转向配额：每个时序格7/8、每个能量水平4/5，总计67/68条隐藏阶段转向 Trial。旋转不发生角速度反号。

## 混合练习

每名被试随机得到摆动5条/旋转4条或摆动4条/旋转5条。两类内部均不重复时序组合，并使三个 `show` 和三个 `hide` 水平的计数差不超过1；九条练习整体随机。

- 摆动练习能量：`40.18 J`；
- 旋转练习能量：`95.55 J`；
- 练习摆动自然抽样转向，不进入正式配额。

## 颜色速度提示

画面运动范围上方和下方各显示一条尺寸固定、颜色同步的水平色块。色块不改变长度，也没有移动指针；颜色只编码瞬时绝对线速度 `v=l|ω|`。

```text
level = clamp(v / 14.515508947329405, 0, 1)
hue = 120° × (1 - level)
color = hsl(hue 80% 45%)
```

因此0 m/s为绿色，半速附近为黄色，实验二正式刺激最大速度 `14.515508947329405 m/s` 为红色。颜色条在可视、淡出和隐藏阶段持续更新，进入估计与反馈阶段后隐藏。

## 完成规则

只有时间线自然结束且正式响应序号完整、唯一覆盖1–180时标记为 `f`；中断、缺失或重复均标记为 `nf`。
