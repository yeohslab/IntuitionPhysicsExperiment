# 实验二：实验设计

## 研究范式

实验二沿用实验一的单摆观察、淡出、遮挡和终态位置估计任务。差异在于速度辅助信息改为上下两条颜色提示，并由同一被试完成摆动和旋转 Block。

## 被试与结构

- 单组设计；被试编号为 `E2-0001` 至 `E2-9999`。
- 1个混合练习 Block，共9个 Trial，全部提供反馈。
- 15个正式 Block，每个9个 Trial，共135个正式 Trial。
- 15个正式 Block 整体真随机排序；被试编号不作为随机种子。

摆动能量范围按与实验一相同的规则等分为11段，剔除最接近临界能量的一段，保留10个能量中点：`5.434545、12.383636、19.332727、26.281818、33.230909、40.18、47.129091、54.078182、61.027273、67.976364 J`。旋转继续使用最低五个保留能量：`85.75、90.65、95.55、100.45、105.35 J`。每个Block完整覆盖对应运动类型的3×3时序组合：

- 摆动 `show_T = 1.25 / 1.5 / 1.75`；
- 旋转 `show_T = 2.5 / 3.0 / 3.5`；
- 两类均为 `hide_sec = 0.8 / 1.0 / 1.2 s`。

摆动正式 Trial 继续近似1:1平衡隐藏阶段转向：每个时序格5条、每个能量水平4/5条，总计45条隐藏阶段转向 Trial。旋转不发生角速度反号。

## 混合练习

每名被试随机得到摆动5条/旋转4条或摆动4条/旋转5条。两类内部均不重复时序组合，并使三个 `show` 和三个 `hide` 水平的计数差不超过1；九条练习整体随机。

- 摆动练习能量：`40.18 J`；
- 旋转练习能量：`95.55 J`；
- 练习摆动自然抽样转向，不进入正式配额。

## 颜色速度提示

画面运动范围上方和下方各显示一条尺寸固定、颜色同步的水平色块。色块不改变长度，也没有移动指针；颜色只编码瞬时绝对线速度 `v=l|ω|`。

```text
level = clamp(v / 14.515508947329405, 0, 1)
hue = 240° + 120° × level
color = hsl(hue 90% 50%)
```

因此0 m/s为蓝色，半速附近为紫红色，实验二正式刺激最大速度 `14.515508947329405 m/s` 为红色。两条色带高28 px、黑色边框2 px，长度保持为摆球运动直径。颜色条在可视、淡出和隐藏阶段持续更新，进入估计与反馈阶段后隐藏。

## 完成规则

只有时间线自然结束且正式响应序号完整、唯一覆盖1–135时标记为 `f`；中断、缺失或重复均标记为 `nf`。
