# 实验二：实验设计（协议 2.0.0）

## 研究范式

实验二沿用单摆观察、淡出、遮挡和终态位置估计任务。速度辅助为上下两条同步 Turbo 颜色条；`show_T` 固定为 `1.2`，**遮挡时长**为 Block 因素。

## 被试与结构

- 单组设计；被试编号 `E2-0001`–`E2-9999`。
- 1 个混合练习 Block（9 Trial，含反馈）。
- 3 个正式 Block，各 50 Trial，共 **150** 条正式 Trial。
- 每个正式 Block 对应一种遮挡时长：`0.7 / 1.0 / 1.3 s`；Block 顺序与 Block 内 Trial 均随机。

## 能量

- 摆动 `[1.96, 78.4] J`：端点均匀 8 点，剔除临界 `78.4 J`，保留 **7** 个水平。
- 转动 `[78.4, 117.6] J`（上界 `1.5 Ec`）：端点均匀 4 点，剔除临界 `78.4 J`，保留 **3** 个水平。
- 合计 **10** 个能量；每个能量在每个 Block 内各 **5** 条 Trial（5 个终点基准）。

## 终点采样

在允许摆角范围内将区间六等分，取 5 个内分点为基准；终点在基准两侧 `A/24`（`A` 为该能量对应幅度）内均匀抽样，再反推初始状态。

## 练习

摆动/旋转 4/5 或 5/4；`show_T = 1.2`；三种遮挡在练习中近似平衡；练习能量取正式摆动/转动能量组的中位水平。

## 颜色速度提示

统一标尺上限为正式最高能量 `117.6 J` 在最低点的线速度；色带规格与 1.0 相同（28 px、4 px 间距、连续 Turbo）。

## 完成规则

时间线自然结束且正式响应序号完整、唯一覆盖 1–150 时标记 `f`。
