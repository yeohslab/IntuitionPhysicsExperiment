# 实验二：验证与复现

执行：

```bash
npm run verify-experiment-2
npm run verify-all
npm run build
```

自动验证包括：

- 1个9 Trial混合练习 Block，以及15×9=135条正式 Trial；
- 按11等分并剔除临界邻近段生成的10个摆动能量，以及固定的最低5个旋转能量；
- 每个正式Block完整覆盖对应运动类型的3×3时序；
- 练习运动类型4/5分配及show/hide边缘近似平衡；
- 摆动正式转向配额（每时序格5、每能量4/5、总计45）和旋转零转向；
- 统一颜色标尺、蓝—紫红—红端点、28 px固定厚度与越界钳制；
- schema v1 JSON/CSV、135条完成判定与文件命名；
- 与实验一独立的sessionStorage、恢复快照和路由。

生产生成使用浏览器真随机源；验证使用固定随机源以复现完整刺激集。
