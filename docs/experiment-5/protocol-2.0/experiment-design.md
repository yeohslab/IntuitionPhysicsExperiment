# 实验五：铃铛可达性（协议 2.0.0）

## 任务

正式阶段分为 40°、60°、80°三个振幅区组。每条试次先用 1 s 提示起始侧和运动方向，再呈现 0.5 s 注视点，然后播放运动。光栅与实验四协议2.0相同，为 G1/G2/G3。可见片段数为光栅编号加 3（G1 为 4，G2 为 5，G3 为 6）。空白开始前的 0.30 s 内，摆球、光栅、振幅弧和铃铛一起变淡，这段时间不另加。随后进入 0.70 s 全屏空白。淡出开始播放掩蔽音并持续到空白结束；作答开始时掩蔽音停止并同时播放提示音。铃铛从运动开始前显示到开始变淡；空白结束后只呈现按键问题，不再显示运动场景或铃铛。

同一振幅使用一个跨三档光栅共享的查询状态。查询状态从每象限六个等缩放弧长中点构成的候选库中选择，并要求三档光栅都能生成各自数量的有效片段，且该状态前的 0.70 s 空白既扫到至少一个铃铛、又扫不到至少一个铃铛。不满足的状态不进入正式区组或练习。被试号按候选顺序轮换查询状态。

## 铃铛条件

高度偏移为 `{-0.50,-0.30,-0.10}` m，全部不高于最大摆高。接触高度为

`hB = l*(1-cos(amplitude)) + deltaH`。

试次全程显示可达弧线，因此铃铛只放在这条弧线之内，不使用高出最大摆角的位置。铃铛放置在左侧或右侧。正确答案只看全屏空白的 0.70 s：摆球中心角度扫过的闭区间（含空白内的转折）覆盖铃铛角度，或与区间边缘相距不超过摆球角半径 `0.08/4` rad，才判为可达。淡出和空白之前的运动都不算。空白没扫到的弧线内铃铛仍为不可达。每个振幅×光栅的6个高度/侧别条件复用完全相同的运动初态、查询态、片段边界和空白时段。同一查询状态下，三档光栅的空白是同一段物理时间，同一高度和侧别的答案相同。

实现同时记录计划与实际的可见转向和可见接触及首次出现帧；这些线索不参与评分或排除。F/J含义按被试号奇偶平衡，作答不设超时。

## 结构

- 50°有反馈练习6条：每档光栅一条可达、一条不可达。可达铃铛不足三个时，同一铃铛可以换光栅重复。左右尽量均衡，以空白是否扫到为准。
- 正式3振幅区组×18条，共54条；每区组完整覆盖3光栅×3高度×2侧别。可达条数由空白扫铃决定。
- 振幅区组顺序按被试号覆盖六种排列。区组内避免连续超过3条相同侧别或光栅。答案的同样限制只在做得到时使用。
- 正式试次无反馈。

模型比较与最优光栅选择属于后续分析，不在浏览器中执行。
