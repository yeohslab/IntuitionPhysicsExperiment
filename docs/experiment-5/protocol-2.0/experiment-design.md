# 实验五：铃铛可达性（协议 2.0.0）

## 任务

正式阶段分为 40°、60°、80°三个振幅区组。每条试次使用与实验四协议2.0相同的G1/G2/G3光栅，显示最后三个可见运动片段，然后进入0.30 s全屏空白。铃铛从运动开始前显示到空白开始；空白结束后只呈现按键问题，不再显示运动场景或铃铛。

同一振幅使用一个跨三档光栅共享的查询状态。查询状态从每象限六个等缩放弧长中点构成的候选库中选择，并要求三档光栅都能生成三个有效片段。被试号按候选顺序轮换查询状态。

## 铃铛条件

高度偏移为 `{-0.50,-0.30,-0.10,+0.10,+0.30,+0.50}` m，接触高度为

`hB = l*(1-cos(amplitude)) + deltaH`。

铃铛放置在左侧或右侧。当且仅当 `deltaH <= 0` 时正确答案为可达。每个振幅×光栅的12个高度/侧别条件复用完全相同的运动初态、查询态、片段边界和空白时段。

实现同时记录计划与实际的可见转向和可见接触及首次出现帧；这些线索不参与评分或排除。F/J含义按被试号奇偶平衡，作答不设超时。

## 结构

- 50°无遮挡完整周期演示一次。
- 50°有反馈练习6条：六档高度各一次、左右3/3、每档光栅两次且可达/不可达各一。
- 正式3振幅区组×36条，共108条；每区组完整覆盖3光栅×6高度×2侧别。
- 振幅区组顺序按被试号覆盖六种排列；区组内避免连续超过3条相同答案、侧别或光栅。
- 正式试次无反馈。

模型比较与最优光栅选择属于后续分析，不在浏览器中执行。
