# 实验五：铃铛可达性（协议 3.0.0）

在协议 2.0 之外新增。整幅只留一条宽 0.45 m 的竖直缝，不是 G1/G2/G3。缝只在出发侧，左右两条边的横坐标都落在从最低点到振幅减 9° 的这一段里：铃铛在左时两边都在 \([0,\ L\sin(\Theta-9^\circ)]\)，铃铛在右时都在左侧镜像。缝中心把这段横坐标分成等份，取每一份的中点：正式每侧 6 份，练习每侧 2 份，不取区间两端。位置在该侧的铃铛偏移之间打乱。摆球在遮挡后面，铃铛画在遮挡前面。振幅仍是 75°、65°、55°，练习为 60°。铃铛仍是相对振幅的 ±3°、±6°、±9°。负偏移可达，正偏移不可达。

摆球从铃铛对侧的最低询问角出发，也就是振幅减 9°。铃铛在左时，55° 从右侧 +46° 出发，65° 从 +56° 出发，75° 从 +66° 出发。初速度符合该振幅能量并朝向铃铛，不先到达外侧最高点。

淡出 0.30 s 之后是 0.20 s 全空白。这段空白结束时，摆球正好到达铃铛侧的振幅减 9°。全空白比原来的 0.10 s 多 0.10 s，可见阶段因此提前 0.10 s 结束，淡出长度不变。画面继续空白，直到该侧最高点。运动一开始就可以按 F/J，一答就结束。

正式阶段 36 条，分成 3 个区组。区组只用来把连续任务分段，段间休息。每个区组都包含 75°、65°、55°，每种振幅 4 条，左右各 6 条，三种振幅在区组内混排。刺激集 schema 为 5，数据 schema 为 2。
