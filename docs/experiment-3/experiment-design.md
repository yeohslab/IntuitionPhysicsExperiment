# 实验三：实验设计

## 研究范式

实验三沿用实验一的单摆观察、淡出、遮挡和终态位置估计任务，以及左右同步的竖向高度速度条；运动条件改为被试内设计，并沿用实验二的 Block 结构。

## 被试与结构

- 单组设计；被试编号为 `E3-0001` 至 `E3-9999`。
- 1个混合练习 Block，共9个 Trial，全部提供反馈。
- 20个正式 Block，每个9个 Trial，共180个正式 Trial。
- 正式 Block 包含15个摆动能量水平和5个低能量旋转水平，整体真随机排序。
- 每个正式 Block 完整覆盖对应运动类型的3×3时序组合；摆动转向配额和混合练习4/5分配均与实验二一致。

## 速度提示

画面左右各显示一条与实验一相同的竖向高度条，两条始终同步。所有摆动和旋转 Trial 使用同一量程：

```text
v = l * abs(omega)
level = clamp(v / 14.515508947329405, 0, 1)
```

速度条在可视、淡出和遮挡阶段持续更新，进入估计与反馈阶段后隐藏。

## 完成规则

只有时间线自然结束且正式响应序号完整、唯一覆盖1–180时标记为 `f`；中断、缺失或重复均标记为 `nf`。
