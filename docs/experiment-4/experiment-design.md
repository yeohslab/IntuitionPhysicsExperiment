# 实验四：实验设计（协议 1.0.0）

## 范式

光栅遮挡下的无阻尼单摆。每个试次的机械能固定为原区间 $[8.48,14.48]\,\mathrm{J}$ 的中点 $11.48\,\mathrm{J}$；摆球在该能量轨道上按运动时间随机选取初始相位，因此初始位置可变且初速度严格非零。被试观看摆球穿过竖条光栅，在询问时刻 $t_q$ 报告该瞬间的**有符号角度**与**速度大小**（色带相对位置）。

## 被试与结构

- 编号 `E4-0001`–`E4-9999`。
- 练习 $3$ 试次（小/中/大间隙各 $1$，有反馈）。
- 正式 $3$ 区组 × $20$ 试次 = **60**；区组对应间隙档，区组顺序随机；区组内不打乱，按固定左右初始位置序列呈现。每个位置侧内向左、向右运动各 $5$ 条。

## 物理与光栅

见 [实验四设计 V1.0](../../数据收集/主试准备/实验四伦理/实验四设计V1.0.md)。

V1.0 锁定：试次前提示初始位置侧与运动方向；不增加无遮挡演示；先按每次通过光栅条的完整遮挡用时分配权重，再在对应的安全询问窗口内均匀抽取 $t_q$，因此单向通过时间越长的光栅条被询问概率越高。$0.15\,\mathrm{s}$ 边界余量只限制询问位置，不改变光栅条权重。转折点本身不附加停留时间，也不作为初始状态。最后一段遮挡右端点截断于预注册的 $10\,\mathrm{s}$。实验四只包含摆动，不包含转动条件。

## 汇报顺序

先角度或先速度，随机均匀平衡：每区组内左、右初始位置各 $10$ 条中两种顺序各 $5$ 条；练习 $3$ 条中两种顺序都出现。

## 显示

实验四使用 $1000\times560$ 逻辑画布，悬挂点位于画面上方，只显示 $-90^\circ$ 至 $+90^\circ$ 的完整下半圆虚线参考。摆长 $4\,\mathrm{m}$、摆球半径和光栅宽度/间隙全部共用同一米制比例尺（约 $116.67\,\mathrm{px/m}$）。刺激、作答与反馈阶段使用相同视口；橙色扇形表示该固定能量下的最大摆角（约 $\pm45.00^\circ$）。运动阶段无动态摆杆和速度色条。汇报色带左端为静止，右端对应固定能量 $11.48\,\mathrm{J}$ 在最低点的速度（约 $4.791659\,\mathrm{m/s}$ 或 $1.197915\,\mathrm{rad/s}$），与训练一相同；因此摆球经过最低点时恰好映射到色带右端。

## 完成规则

正式响应序号完整覆盖 $1$–$60$ 且时间线自然结束 → `f`。

协议号与文件名保持 `1.0.0` / `v1.0`。内部刺激 schema 为 4，数据 schema 为 5；旧 schema 3 刺激缓存不可恢复。
