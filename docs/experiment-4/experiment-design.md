# 实验四：实验设计（协议 1.0.0）

## 范式

光栅遮挡下的无阻尼单摆。每个试次的机械能固定为原区间 $[8.48,14.48]\,\mathrm{J}$ 的中点 $11.48\,\mathrm{J}$；摆球在该能量轨道上按运动时间随机选取初始相位，因此初始位置可变且初速度严格非零。被试观看摆球穿过竖条光栅，在询问时刻 $t_q$ 报告该瞬间的**有符号角度**与**速度大小**（色带相对位置）。

## 被试与结构

- 编号 `E4-0001`–`E4-9999`。
- 练习 $3$ 试次（可见窗口数 $N=2/3/4$ 各 $1$，有反馈）。
- 正式 $3$ 区组 × $20$ 试次 = **60**；区组对应可见窗口数 $N=2/3/4$，区组顺序随机；区组内不打乱，按固定左右初始位置序列呈现。每个位置侧内向左、向右运动各 $5$ 条。

## 物理与光栅

见 [实验四设计 V1.0](../../数据收集/主试准备/实验四伦理/实验四设计V1.0.md)。

V1.0 锁定：试次前提示初始位置侧与运动方向；不增加无遮挡演示。询问点只在完全遮挡的可询问位置中抽取，权重是摆球中心走过的轨迹弧长：同一段弧上每个位置等概率，弧长更长的遮挡段被抽到的概率更高。通过时间长、速度慢本身不增加权重；遮挡段内若折返，去程和回程都计入弧长。$0.15\,\mathrm{s}$ 边界余量只把遮挡段两端排除出可询问位置。转折点本身不附加停留时间，也不作为初始状态。最后一段遮挡右端点截断于预注册的 $10\,\mathrm{s}$。实验四只包含摆动，不包含转动条件。

透明观察宽度固定为 $G=0.450000\,\mathrm{m}$，通过改变遮挡条宽度、周期和相位偏移操纵一次完整左→右横穿中的可见窗口数。`gratingOffsetM` 是编号 $k=0$ 的遮挡条中心坐标，其他条中心为 $x_k=\mathrm{offset}+kP$。

| $N$ | $G$ (m) | 遮挡条宽 $B$ (m) | 周期 $P$ (m) | offset (m) |
| ---: | ---: | ---: | ---: | ---: |
| 2 | 0.450000 | 2.378427 | 2.828427 | 0 |
| 3 | 0.450000 | 1.435618 | 1.885618 | 0.942809 |
| 4 | 0.450000 | 0.964214 | 1.414214 | 0 |

计入 $0.08\,\mathrm{m}$ 摆球半径后，每个整球完全可见区间的空间宽度均为 $0.45-2\times0.08=0.29\,\mathrm{m}$；按实际 $11.48\,\mathrm{J}$ 摆幅，一次左→右横穿分别包含 2、3、4 个这样的连通区间。光栅关于支点 $x=0$ 镜像对称：$N=2/4$ 时中央遮挡条中心在支点，$N=3$ 时中央透明间隙中心在支点。

## 汇报顺序

先角度或先速度，随机均匀平衡：每区组内左、右初始位置各 $10$ 条中两种顺序各 $5$ 条；练习 $3$ 条中两种顺序都出现。

## 显示

实验四使用 $1000\times560$ 逻辑画布，悬挂点位于画面上方。比例尺仍按完整下半圆（摆长 + 摆球半径）留白，刺激、作答与反馈使用同一视口和同一组 $G/B/P/\mathrm{offset}$ 光栅参数。各阶段虚线范围都是该固定能量下的最大摆角（约 $\pm45.00^\circ$），不是 $-90^\circ$ 至 $+90^\circ$ 的半圆。所有物理宽度共用同一米制比例尺（约 $116.67\,\mathrm{px/m}$）。运动阶段无动态摆杆和速度色条。汇报色带左端为静止，右端对应固定能量 $11.48\,\mathrm{J}$ 在最低点的速度（约 $4.791659\,\mathrm{m/s}$ 或 $1.197915\,\mathrm{rad/s}$）；因此摆球经过最低点时恰好映射到色带右端。训练一色带另行按 $60^\circ$ 静止释放标定，两者不再共用尺度。

## 完成规则

正式响应序号完整覆盖 $1$–$60$ 且时间线自然结束 → `f`。

协议号与文件名保持 `1.0.0` / `v1.0`。内部刺激 schema 为 6，数据 schema 为 6，刺激导出 schema 为 3；旧 schema 5 刺激缓存不可恢复。
