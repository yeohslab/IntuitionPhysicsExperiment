# 实验设计

## 研究范式

本实验考察运动信息消失后，被试对单摆状态的内部模拟。被试先观察真实运动，摆杆和小球随后淡出，隐藏阶段只保留运动范围轨迹。提示音响起后，被试点击并拖动摆杆，报告隐藏阶段结束的方向。

## 被试信息与分组

| 字段 | 规则 |
|---|---|
| `subject_id` | 1–9999，保存为四位字符串 |
| `motion_group` | `1` 摆动；`2` 旋转 |
| `gender_code` | `0` 男；`1` 女 |
| `age_years` | 1–120 的整数 |

性别使用固定选项，年龄输入拒绝空值、小数、负数和越界值。本版本不额外设置成年资格限制；知情同意与招募资格仍须由研究方案决定。

## 设计与 Trial 数

实验是 2（运动组别，组间）× 3（可视时长，组内）× 3（遮挡时长，组内）的混合设计。

| 组别 | 运动 | `show_T` | `fade_T` | 正式最高 Block 能量 |
|---|---|---|---|---|
| 1 | 摆动 | 1.25 / 1.5 / 1.75 | 0.25 | 71.23375 J |
| 2 | 旋转 | 2.5 / 3.0 / 3.5 | 0.5 | 154.35 J |

两组 `hide_sec` 均为 `0.8 / 1.0 / 1.2 s`。每个练习或正式 Block 包含完整 3×3 时序组合，顺序随机。结构为 1 个练习 Block（9 Trial）和 15 个正式 Block（135 Trial）。

## 物理模型

固定质量 `m=1 kg`、杆长 `l=4 m`、重力 `g=9.8 m/s²`，最低点势能为零。角度 `theta=0` 表示竖直向下，顺时针为正，记录时折返到 `(-π, π]`。

机械能为：

```text
E = 0.5 m (lω)² + mgl(1-cosθ)
```

摆动使用 Jacobi 椭圆函数解析解；旋转使用 Velocity Verlet，最终生成验收、运行与导出均使用不大于 `1/4000 s` 的子步。生成器搜索可使用 `1/800 s` 粗步，候选 Trial 最终以高精度入口重新验收。

每个 Trial 满足：

- 初始能量属于对应 Block；
- 设计结束角与抽样目标的误差不超过 1°；
- 隐藏阶段角速度不变号，不经过转向点；
- 屏幕终态、CSV 和刺激 JSON 的 `x_t` 均由同一设计时刻状态函数计算。

## 绝对速度条

速度条为 `v=l|ω|`，左右两条显示同一值。填充比例：

```text
clamp(l * abs(omega) / V_max_group, 0, 1)
```

`V_max_group` 从该组正式 Block 的最高能量在最低点的速度计算：

- `V_max_A = 11.9359750335 m/s`
- `V_max_B = 17.5698605572 m/s`

每个 Trial 均记录 `speed_bar_v_max_m_per_sec`。

## 单 Trial 阶段

```text
注视点 → 可视 → 淡出 → 隐藏 → 点估计 → 练习反馈（仅练习）
```

仿真 `t=0` 在初始化完成后、首个动画帧注册前设置。标签页隐藏时暂停仿真物理时钟和掩蔽音，返回后从相同仿真时间继续；后台停留不计入刺激时长，但计入暂停质控字段。

## 完成、中断与恢复

仅当 jsPsych 时间线自然结束，并且正式响应的 `formal_trial_index` 恰好覆盖 1–135 时，状态为 `f`。所有显式中断、异常提前结束、零响应、部分响应或重复/缺失响应均为 `nf`。

完整刺激集在独立 Web Worker 中生成，以免物理拟合长时间阻塞页面主线程。生成完成后立即保存人口学信息、刺激集和 `generated` 恢复阶段；此时刷新可恢复到“可直接开始”的状态。恢复快照还会在每个时间线单元开始/结束、物理阶段切换、作答确认、`pagehide` 和 `beforeunload` 时更新。实验一旦进入时间线，中断 Trial 不恢复继续作答，避免再次观看部分刺激；其完整物理参数仍保存在原刺激集中。
