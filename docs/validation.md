# 仿真与协议验证

## 自动验收

```bash
npm run verify-all
```

该命令依次验证：

1. 椭圆函数周期、摆动解析解初值与能量；
2. 旋转 Velocity Verlet 的能量漂移和高精度参考终态；
3. 两组完整运行时刺激生成、3×3 时序、能量、终态误差与隐藏无转向；
4. 角度折返与误差；
5. schema v2 的 144 Trial、固定组内 Vmax、CSV 共有字段、人口学校验和 `f/nf` 判定；
6. 所有恢复阶段、响应快照和首次存储失败阻断。

生产构建另外执行严格 TypeScript 检查。

完整刺激集的物理拟合属于重计算任务。生成器运行在独立 Web Worker 中，并按 Trial 向首页报告 `0–144` 的进度，避免阻塞浏览器 UI 主线程。浏览器回归测试覆盖确认后页面持续响应、生成完成、刷新恢复待开始状态以及恢复后进入实验。

分析兼容性可在 Python 环境中执行：

```bash
uv run python tests/verification/verify_analysis_compat.py
```

## 物理精度

- 摆动使用解析解，测试覆盖零/非零初始角速度；`t=0` 角度误差约 `1e-14 rad` 量级。
- 旋转运行积分子步不大于 `1/4000 s`，与 `1/40000 s` 参考积分比较，终态角和角速度误差阈值均为 `1e-4`。
- 旋转 4–5 周期相对能量漂移阈值为 `1e-6`；当前代表性测试通常约 `3e-8`。
- 生成器要求能量误差不超过 `2e-3 J`、目标终态角误差不超过 1°，并逐 Trial 验证隐藏段无转向。

## 时间精度

`performance.now()` 的起点设置在初始化完成、首帧注册之前。每帧只用墙钟换算目标仿真时刻；旋转积分器推进到该目标，摆动解析解直接求该时刻状态。估计界面的真值不取最后一帧，而由统一的设计结束状态函数重新计算。

浏览器调度不能保证恰在设计结束毫秒绘制，因此记录帧数、最大帧间隔、结束 overshoot 和实际活动时长。标签页隐藏时取消动画、停止掩蔽音并冻结物理时钟，返回后继续。

## 已知限制

- `requestAnimationFrame` 受设备负载、刷新率和浏览器节流影响；质控字段用于试点后制定排除标准。
- 页面关闭瞬间不能可靠触发下载。恢复依赖同一浏览器中的 `localStorage`，不等同于后端上传。
- 生成中的 Worker 尚未产出完整刺激集；若浏览器在生成完成前被强制终止，需要重新生成。生成成功后会立即保存恢复快照。
- 浏览器可能拦截同一动作触发的多个下载；运行结束页和恢复窗口均允许分文件重复下载。
- 清除站点数据、设备损坏或不再打开实验页面会使纯静态恢复不可用。
- 自动测试覆盖确定性物理与协议逻辑；正式上线前仍需在目标浏览器、屏幕、音频设备和低性能设备上做人工试运行。
